Static site package (GitHub Pages ready)
Files:
- index.html, projects.html, about.html
- css/styles.css
- components/header.html, components/footer.html, components/project-card.html
- react-components/*.jsx (Header, ProjectCard, Footer)

How to use:
- Drop the folder into a GitHub Pages repository (root) or into a branch named 'gh-pages'.
- Replace the hero image by editing the `.profile-pic` div or by adding an <img src="assets/hero.png"> and placing the file in `assets/`.
- To make it pixel-perfect: replace fonts (Apercu) by hosting font files in css/@font-face or use Google Fonts; adjust sizes in css/styles.css.

If you want, I can embed screenshots from the live site into the hero and project cards — tell me and I'll update the package.
